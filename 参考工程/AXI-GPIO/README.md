# AXI-GPIO测试工程（点灯）
学习任何GPIO的第一步便是：~~烧坏这个GPIO~~拿这个GPIO点亮LED，百度大脑这块板子留给我们做实验用的LED是电源旁边的指示灯，这是一个双色指示灯，用红色部分表示供电状态，绿色部分供我们操作

看硬件手册可以知道这个灯和IO的关系是灌电流模式，即IO输出低电平电流从电源经过灯灌入IO，灯亮；IO输出高电平电流无法流通，灯不亮
## 介绍
AXI-GPIO是使用起来相当简单的GPIO了，使用可以参考这篇[教程](https://blog.csdn.net/2303_76814451/article/details/147111519)，不过在我的工程中我知道这个GPIO只用作输出，所以我勾选了`All Outputs`这个选项，这个不是很重要；另外一个点就是教程中让GPIO输出0电平用的是`XGpio_DiscreteClear`函数，这个效果上和我代码中直接写0是一样的
